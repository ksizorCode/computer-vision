# Automatizando tareas con Coputer Vision a partir de la captura de pantalla en tiempo real

Pueden existir diferentes campos y ámbitos:

|Término|	Explicación|
|---------------------|----------------|
|**GUI Automation** (Automatización de interfaces gráficas)	| Es el término general para cualquier software que interactúa con la interfaz de usuario (clics, escritura, scroll, etc.) automáticamente. PyAutoGUI, SikuliX o AutoIt son ejemplos.|
|Screen Scraping| Originalmente se refiere a “extraer información de la pantalla” de forma automática. Puede incluir hacer clic si la extracción se interpreta y se actúa sobre ella.|
|Template Matching / Computer Vision|	Técnica de visión por computadora donde se busca un patrón o imagen (plantilla) dentro de otra imagen (pantalla). En tu caso, OpenCV hace el template matching para localizar los elementos.|
|Botting / Macro|	En videojuegos o software repetitivo, se llama bot o macro a un programa que hace acciones automáticas en la pantalla.|
|RPA (Robotic Process Automation)|	En entornos empresariales, esto se llama RPA: automatizar tareas repetitivas de escritorio, muchas veces mediante reconocimiento visual de la pantalla.|
